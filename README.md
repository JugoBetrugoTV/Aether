# Aether

**All-in-One World of Warcraft Addon**

Aether combines the best features of Titan Panel and Leatrix Plus into a single, powerful, and user-friendly addon.

## Features

### Titan Panel Features
- **Information Bar System**: Multiple configurable bars (top and bottom)
- **Built-in Plugins**: Bag space, Clock, Gold, Location, Performance (FPS/Latency), Repair, Volume, XP
- **LibDataBroker Support**: Compatible with LDB plugins
- **Profile System**: Save and switch between different configurations

### Leatrix Plus Features

**Automation:**
- Auto-accept and turn-in quests
- Auto-repair (with guild bank option)
- Auto-sell junk items
- Faster auto-loot
- Auto-accept summons and resurrections

**Social:**
- Block duels and pet battle duels
- Block party/friend/guild invites
- Auto-accept from friends and guild

**Chat:**
- Hide combat log and chat buttons
- Move edit box to top
- Class colors in chat
- Disable chat fade
- Increase chat history

**Interface:**
- Square minimap
- Enhanced tooltips (item level, spec, class colors)
- Minimap button management

**System:**
- Max camera zoom distance
- Mute game sounds
- Easy item destruction
- Faster movie skip

## Installation

1. Download the latest release
2. Extract the `Aether` folder to your `World of Warcraft\_retail_\Interface\AddOns\` directory
3. Restart World of Warcraft or reload UI with `/reload`

## Usage

Type `/aether` or `/ae` to open the configuration panel.

### Commands
- `/aether` - Open configuration
- `/aether panel` - Toggle the panel
- `/aether reset` - Reset all settings to defaults

## Requirements

- World of Warcraft: The War Within (11.0.2+) or Midnight (12.0.0+)
- No other addon dependencies required (all libraries embedded)

- CallbackHandler-1.0
- Ace3 Libraries (AceAddon, AceDB, AceEvent, AceTimer, AceConsole, AceHook, AceLocale, AceConfig, AceGUI, AceDBOptions)
- LibSharedMedia-3.0
- LibDBIcon-1.0
- LibDataBroker-1.1
- LibQTip-1.0
